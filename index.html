Dataset release

17,621 validated NL2GraphQL instances

The corpus spans 173 schemas and seven query categories. The 9,118-instance training set and the 6,403-instance public benchmark are released under the MIT License at nl2graphql-bench/datasets. The 2,100-instance hidden benchmark is not released: it is what we score submissions against, so if it were public a model could be tuned on it and the score would mean nothing.

About the benchmark

Text-to-SQL has Spider and BIRD. GraphQL has a different problem.

Enterprise GraphQL APIs are schema-specific: each organization exposes its own types, fields, arguments, filters, and mutations. A model that works on one API may fail on the next. AutoGraphQL is designed around that reality: bring a schema, generate validated data for it, adapt a model, and evaluate whether the model generalizes to schemas it did not see in training.

Each instance is a validated triple — (schema, natural-language query, ground-truth GraphQL query) — synthesized through schema-aware query generation, then checked for both syntactic validity and successful execution before it's admitted to the corpus.

  • Cross-schema, not fixed-schema. The 104 training, 49 public-benchmark, and 20 hidden-benchmark schema sets are pairwise disjoint.
  • Construct-level diagnosis. Toggle the leaderboard's category breakdown to see aliases, directives, fragments, filters, pagination, and mutations individually.
  • Execution-validated ground truth. Every reference query is schema- and execution-checked, then deduplicated by canonical structure.
  • A genuinely withheld benchmark. 2,100 instances across 20 schemas are not released and are reserved for future evaluation.
GraphQL context What the language is and why each schema changes the task

GraphQL is an open-source query language and runtime for APIs. Every service defines its own typed schema, so a generated query must use the fields, arguments, types, and relationships that the target API actually exposes. This schema dependence is the central challenge that AutoGraphQL measures.

Research lineage Five earlier papers that led to AutoGraphQL. Accuracies are not comparable across them: the evaluation metric changed over the series, from comparing execution output to the semantic-equivalence AST scoring used here.
  1. IJCAI 2024 · Demo LLM-powered GraphQL Generator for Data Retrieval ↗

    An initial pipeline for translating natural-language requests into GraphQL queries.

  2. EMNLP 2024 · Industry GraphQL Query Generation: A Large Training and Benchmarking Dataset ↗

    The first large training and evaluation resource in this research program.

  3. NAACL 2025 · Industry Schema and Natural Language Aware In-Context Learning ↗

    Schema structure and natural-language similarity guide the selection of demonstrations.

  4. IEEE ICWS 2025 Robust Evaluation of LLM-Generated GraphQL Queries ↗

    RGEval evaluates semantic equivalence beyond exact string matching.

  5. SIGMOD 2026 · SynthAI Synthetic Data Generation for Schema-Aware Query Interfaces ↗

    A preliminary study covering 1,845 instances across 20 schemas.

  6. EMNLP 2026 · Best Paper AutoGraphQL: A Bring-Your-Own-Schema Framework ↗

    The unified framework scales the resource to 17,621 instances across 173 schemas.
